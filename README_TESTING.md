## ?? Quick Help

### API won't start?
1. Check: .NET 8 SDK installed
2. Run: `dotnet build`
3. Check: Port 5000 available
4. Try: `dotnet run` from BlogApp.Api folder

### Test tool won't connect?
1. Check: API is running
2. Check: Token is valid
3. Check: Browser console (F12) for errors
4. Try: Refresh page

### Database issues?
1. Run: `dotnet ef database update`
2. Check: Connection string valid
3. Try: Rebuild solution
4. Check: SQL Server/LocalDB running

### Need more help?
1. Check: `QUICK_REFERENCE.md` ? Common Errors
2. Check: `TESTING_GUIDE.md` ? Troubleshooting
3. Check: API console output
4. Try: Re-reading relevant guide
